# Smart Stock demo

PHP/XAMPP inventory and completed sales app with a local Python sales baseline and Stock History.

- [Set up the app and Python service](GROUPMATE_SETUP.md)
- [Upload this clean copy to GitHub](GITHUB_UPLOAD.md)
- `database/groupmate_clean_setup.sql` contains schema, locations, and one demo store. It contains no previous users, passwords, products, or sales.

Each teammate makes their own local `1st prog/php/config/db_connection.php` from the tracked example. The real connection file and private database exports are excluded from Git.
